Configuración y Credenciales

Para usar la API pública, debes incluir la siguiente cabecera en todas tus solicitudes:

Header: X-API-KEY
Value: **********

Alternativamente, puedes pasarla como parámetro de consulta: ?apiKey=TU_CLAVE

https://vps-4455523-x.dattaweb.com/jpupper/api/public
Endpoints de Proyectos
GET /projects

Obtiene todos los proyectos del sistema.

curl -H "X-API-KEY: YOUR_API_KEY" https://vps-4455523-x.dattaweb.com/jpupper/api/public/projects
GET /projects/:id

Obtiene los detalles de un proyecto específico.

curl -H "X-API-KEY: YOUR_API_KEY" https://vps-4455523-x.dattaweb.com/jpupper/api/public/projects/babylon-js
POST /projects

Crea un nuevo proyecto.

curl -X POST -H "Content-Type: application/json" -H "X-API-KEY: YOUR_API_KEY" \
-d '{
  "id": "new-project",
  "title": "Nuevo Proyecto",
  "description": "Descripción del proyecto",
  "url": "https://example.com",
  "tags": ["web", "design"]
}' \
https://vps-4455523-x.dattaweb.com/jpupper/api/public/projects
PUT /projects/:id

Modifica un proyecto existente.

curl -X PUT -H "Content-Type: application/json" -H "X-API-KEY: YOUR_API_KEY" \
-d '{
  "title": "Título Actualizado"
}' \
https://vps-4455523-x.dattaweb.com/jpupper/api/public/projects/new-project
DELETE /projects/:id

Elimina un proyecto.

curl -X DELETE -H "X-API-KEY: YOUR_API_KEY" https://vps-4455523-x.dattaweb.com/jpupper/api/public/projects/new-project
Endpoints de Presupuestos

GET /budgets

Obtiene todos los presupuestos.

curl -H "X-API-KEY: YOUR_API_KEY" https://vps-4455523-x.dattaweb.com/jpupper/api/public/budgets
GET /budgets/:id_o_codigo

Obtiene un presupuesto por su ID de base de datos o su código alfanumérico.
